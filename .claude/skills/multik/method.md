# Методика монтажа «Скилла Мультик»

Читай этот файл целиком перед раскадровкой и сценами. Порядок работы, онбординг и выбор донора — в [SKILL.md](SKILL.md): сюда приходим на шаге «Производство → 4».
Все команды — из папки студии `multik/`. Свой стиль — `style/STYLE.md` и `src/theme.ts`, свой герой — `src/hero/current.ts`: сцены берут их сами.

## Когда подходит

Берись, если в тексте есть цепочка конкретных действий: инструкция по шагам, «как это устроено», рабочий процесс, разбор инструмента, «N ошибок / N способов». Один рассказчик. Каждой фразе нужен предмет, который можно показать.

Плохо подходит: чистое рассуждение без предметов, диалог двух героев, история с живыми людьми. Скажи об этом и предложи переписать текст под действия.

## Вход

- **Текст или сценарий.** Слова человека — это и есть озвучка: не переписывай их, только разбей на фразы. Слишком длинно (больше ~60 с) или без действий — предложи сокращение одним списком и дождись ответа.
- **Ролик-донор** (из трендов или по ссылке). Разбор через `xray_video` — в SKILL.md. Разбери механику: что происходит каждые 0,5 с, какие объекты, как связаны с речью, какие переходы. Донор задаёт механику, а не оформление: его кадры, тексты, ники, цифры и интерфейсы не переносим. Текст пишем свой.
- **Только тема.** Напиши текст на 20–45 с в форме «хук → шаги → итог», покажи человеку и дождись «ок» до раскадровки.

Числа и названия в тексте озвучки пиши так, как их произносят («семьдесят два», «Клод Код»), если голос будет синтезом.

## Шаги

### 1. Папка ролика
`films/<slug>/` — копия `examples/demo/`: `chunks.txt`, `cues.json`, `storyboard.md`, `scenes.tsx`, `sfx.json` и `Demo.tsx` → `Movie.tsx` (компонент `Demo` переименуй, например в `MyFilm`). Импорты `../../src/...` остаются те же. Зарегистрируй композицию в `src/Root.tsx` (после шага 4, когда появится `props.json`):

```tsx
import {MyFilm} from '../films/<slug>/Movie';
import myProps from '../films/<slug>/props.json';
<Composition id="MyFilm" component={MyFilm} width={1080} height={1920} fps={30}
  durationInFrames={myProps.durationInFrames} defaultProps={myProps as FilmProps} calculateMetadata={fromProps} />
```

### 2. Раскадровка по словам — до любой анимации
`storyboard.md`, таблица как в демо. Под каждой фразой:
- метка шапки `// 04 · шаг 2 · папка`;
- главный объект сцены и что с ним происходит **на каждом смысловом слове**;
- ударный заголовок: 1–3 слова, одно — акцентом;
- «состояние» внизу слева: чек-лист, подсказка, счётчик, итоговый предмет;
- поза героя.

Плотность — 2–4 события в секунду. Событие — появление, клик, галочка, круг, печать текста, штамп, смена заголовка. Абзац текста на экране вместо действия — брак. Приём под слово — по каталогу ниже.

### 3. Субтитры и якоря
- `chunks.txt`: одна строка — одна фраза субтитра (1–2 строки на экране, ~25–40 символов), сброс на смысловой границе. `*слово*` — акцент (рукописный, цветом акцента), 1 на фразу, только суть.
- `cues.json`: `"имя": ["слово", номер_вхождения]` — моменты, к которым привязаны события. Сцены ссылаются только на якоря, не на секунды: тогда после смены озвучки всё переезжает само.

### 4. Голос и тайминги
Голос — по выбору из онбординга (`setup.json → voice.mode`): своя запись (`public/<slug>/voice.wav`) или клон ElevenLabs — `python3 scripts/voice.py say films/<slug>/voice.txt -o public/<slug>/voice.mp3` (сначала без `--yes`: план и число символов, затем с `--yes`). Без голоса — синтетические тайминги для черновика.

`python3 scripts/prep.py films/<slug>/chunks.txt films/<slug>/cues.json -o films/<slug>/props.json` и один из режимов:
- `--synthetic` — без аудио, темп по слогам. Для черновика и проверки раскадровки.
- `--audio public/<slug>/voice.mp3 --whisper small` — локальное распознавание (нужен `pip install faster-whisper`).
- `--audio public/<slug>/voice.mp3 --words asr.json` — слова с таймингами из любого распознавателя.

Голос клади внутрь `public/` — тогда он сам подключится к ролику. Слова на экране всегда из `chunks.txt`; ASR даёт только время. `chars_matched` ниже 0,95 — разберись до сцен (другой текст в озвучке, числа цифрами). Скрипт печатает время каждого якоря — сверь с раскадровкой.

### 5. Сцены
Пиши `scenes.tsx` по раскадровке из библиотеки `src/lib` (список ниже). Правила:
- Каждая сцена — компонент, который сам решает, когда он виден: `const {t, c} = useFilm(); if (t < c.p1 || t >= c.p2) return null;`.
- Время — только `c.имя ± смещение`. Опечатка в имени якоря даст понятную ошибку.
- Объект входит «шлепком» (`pop`, `enter`), уходит за 4–5 кадров. Склейки жёсткие, кроссфейдов нет.
- Причинность: курсор едет (`curPath`) → клик (`Cursor click`) → меню/выделение → результат. Ничего не появляется «просто так».
- Сцена — зона y 600–1350, заголовок — y 500, состояние — x 110–520, y 1360–1650. Правее x ≈ 600 ниже y ≈ 1380 — герой: туда ничего важного.
- Пометки (зачёркивание, галочка, круг) рисуй внутри контейнера объекта, если объект двигается.
- Реквизит-праздник (конфетти, лучи) уходит через 1–2 с.

В `Film`-компоненте ролика (как `Demo.tsx`): трек поз героя (смена ~раз в секунду по смыслу), полутоновые шторки перед крупными шагами (`badge` — номер шага в темноте), тёмная вспышка перед итогом, свечение у героя на «самом интересном» и в финале, `boardUntil` — до какого якоря фон «доска» (хук).

### 6. Проверка кадров — до полного рендера
```bash
npx tsc -p tsconfig.json
node scripts/stills.mjs MyFilm out/stills --cues --sheet     # кадр через 0,25 с после каждого якоря + листы
```
Открой листы и **посмотри глазами** каждый. Исправь всё из «Частых дефектов». Повтори, пока листы чистые. Отдельные места — `--frames 120,121,122` или `--every 0.25` на хуке и переходах.

### 7. Звуки
`sfx.json` — список событий на якорях (формат в шапке `scripts/sfx.py`): щелчки на кликах, тики на влетающих буквах, удар на штампе, свист на шторке, клавиши на печати. `python3 scripts/sfx.py films/<slug>/props.json films/<slug>/sfx.json -o public/<slug>/sfx.wav` — путь сам впишется в props. Музыки нет: звучат только события.

### 8. Рендер и отправка
```bash
npx remotion render src/index.ts MyFilm out/<slug>.mp4
```
Мало памяти — куски `--frames=0-329`, `--frames=330-659`… и склейка `ffmpeg -f concat`. Громкость голоса — около −14 LUFS, пик ≤ −1 dBFS (сведи голос заранее).
Telegram настроен (`setup.json → telegram.chat_id`) — `python3 scripts/send_telegram.py send out/<slug>.mp4 --caption-file films/<slug>/description.txt`.

### 9. Приёмка
Пройди чек-лист ниже по готовому MP4, а не по коду. Если был образец — `scripts/compare.py` даёт лист «образец / наш» по одинаковым событиям.

## Система знаков

- Тёмная плашка шага: белая цифра и точки прогресса, текущая — акцент. Шаг открывается огромной плашкой в тонком круге (`StepBadge`), затем она улетает в угол объекта.
- Акцент — только суть: акцентное слово, маркерный круг (`Ring`), подчёркивание, рамка (`Frame`), штамп, активный пункт, галочка/крест в круге (`Mark`).
- Тень карточек, окон и героя — полутоновые точки со сдвигом 10–18 px (`HT`).
- Главы разделяет полутоновая шторка до тёмного с плашкой следующего шага; перед итогом — тёмная вспышка 2 кадра.

## Каталог «слово → приём»

| В речи | В кадре |
|---|---|
| хук «все делают / никто не показывает» | доска: меловые кадры рисуются, карточка на скотче шлёпается, лист перекрывает с огромным «КАК?» и кругом |
| «покажу всё / вот N шагов» | карточки шагов веером ложатся на дорогу-змейку, «N ШАГОВ», обводка прыгает по шагам в такт |
| название инструмента / приложения | значок проявляется из пунктирного контура, подпись с подчёркиванием |
| «не делай X» | X наезжает, двойное зачёркивание, уезжает в угол с крестом |
| действие в интерфейсе | окно (`AppWindow`, `FileWindow`, `Browser`), курсор по кривой, клик с кольцом, меню, выбранный пункт, результат |
| «назови / введи» | имя печатается по буквам в поле, подсказка «впиши имя / жми ↵», клавиша загорается |
| «положи / здесь хранится» | папка, файл летит под курсором внутрь, крышка открывается, путь дописывается |
| «чтобы A, B, C» | три пунктирных «?» превращаются в карточки по словам |
| «напиши / попроси» | огромная строка ввода (`InputBar`), текст печатается в такт речи, «↑ НАПИШИ ЭТО», счётчик слов |
| «он сам сделает» | окно агента с чек-листом 0/3 → 3/3, крутилка на активном пункте, под окном карточка текущего действия |
| «например: …» | огромные кавычки, пример печатается по словам |
| «проверяет» | столбики/кадры, лупа идёт по ним, галочки, штамп «ОК» |
| «если не так — скажи» | готовый результат «ДО», пузырь речи героя, правка уходит в окно, «ПОСЛЕ ✓» |
| число | счётчик набегает до значения (`Counter`), вокруг разлетаются частицы |
| «самое интересное» | шторка, конфетти, лучи и свечение у героя |
| «вот и всё» | маршрут возвращается, галочки бегут 1 → N, флажок, рамка, штамп «ГОТОВО» |
| призыв в конце | то действие, которое просишь сделать: поле комментария, кнопка, команда в терминале |

Не нужно показывать всю библиотеку в одном ролике: приём выбирается по смыслу фразы.

## Герой

Герой студии задан в `src/hero/current.ts`: пусто — встроенный Бип, после онбординга — свой герой по фото (`atlasHero(rig)`). Позы у обоих одинаковые, трек поз не меняется. Бип (`src/hero/Mascot.tsx`): векторный робот с экраном-лицом. Рот — по громкости голоса (`props.amplitude`), без аудио — по таймингам слов; моргание, дыхание, эквалайзер на груди. Лист всех поз — композиция `Poses`.

| Смысл слова | Поза |
|---|---|
| анонс, «сначала», главный тезис | `up` |
| объяснение, перечисление | `palm` |
| указать на объект | `point` |
| восторг, итог, «самое интересное» | `celebrate` |
| «никто», неожиданность | `surprise` |
| сомнение, «проверяет», «что-то не так» | `think` |
| «не нужно», развести руками | `shrug` |
| завершение шага | `wink` |
| пауза, нейтрально | `neutral` |

Свой герой из PNG-атласа: `src/hero/AtlasHero.tsx` (формат `rig.json` в шапке файла). Подключается для всей студии через `scripts/atlas_rig.py --install` или для одного ролика — `hero={atlasHero(rig)}` в `<Film>`. Рот открывается наложением по `mouth`/`mouthW`, моргание — по `eyes`/`skin`.

## Внешний вид

Дизайн-система студии — `style/STYLE.md` (палитра, фон, шрифты, сетка, движение, переходы, тени, подходящие приёмы), её код — `src/theme.ts`. Встроенный стиль: акцент кобальт, фон кремовая миллиметровка, хук грифельная доска, шрифты Onest / Oswald / Caveat / JetBrains Mono. Поменял `T.accent` — поменялись все круги, штампы и акцентные слова. Шрифт меняется заменой импорта из `@remotion/google-fonts` (с кириллицей и латиницей). Новый приём из стиля человека, которого нет в библиотеке, — новый компонент в `src/lib`, а не картинка.

## Частые дефекты

- Длинный заголовок заезжает под плашку шага или за край: размер по длине (100–124 px), проверь правый край ≤ 880 px при плашке в углу.
- Заголовок касается окна: окно начинается не выше y ≈ 650.
- Длинные подписи в карточках и чек-листах переносятся: `whiteSpace: 'nowrap'` и размер по длине.
- Что-то важное в зоне героя (x > 600, y > 1380) — уноси левее.
- Пометка нарисована отдельно от движущегося объекта и «отрывается» — рисуй внутри контейнера.
- Слово заголовка, которое звучит позже, не «влетает» — задай сегменту своё `at`.
- Статичная пауза больше 0,5 с — добавь событие: тик счётчика, прыжок обводки, курсор, печать.
- Акцент на трёх местах сразу — оставь один.
- Реквизит висит до конца сцены — убери через 1–2 с.
- Субтитр в две строки перекрывает заголовок — короче фраза в `chunks.txt`.
